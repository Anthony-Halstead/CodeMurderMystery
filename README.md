Murder At Hollowstone Manor - 

Welcome to our Game portfolio project! This project is a collaborative effort aimed at creating a murder mystery experience as part of our group portfolio. This prototype is built using Unity and showcases our skills in game development, design, and collaboration.

🚀 Project Overview

This game prototype involves diverse puzzles and clue mechanics aimed at discovering the murderer with a focus on:

Immersive environments: Created using modern 3D tools and assets.

Player mechanics: Smooth controls and interactions.

Level design: Thoughtfully designed levels to provide both exploration and challanging puzzle mechanics.

📅 Project Status

Current phase: Prototype

🎮 Features

Clue finding/reporting: Sign off on clues in the clue tracker, report your findings to the officer.

Puzzle solving: complete various puzzle laid out around the map.

Dialogue: Talk to npcs to discover more clues.

Crafting: Craft items to use in puzzles.

Rest: Rest in a bed to unlock potential new clues the next night.

🛠 Tech Stack & Tools

Game Engine: Unity 2023.2

Languages: C#

Version Control: GitHub

Tools Used: Jira

🗂 Setup & Installation

To run the project locally, follow these steps:

Clone the repository:


git clone https://github.com/Anthony-Halstead/CodeMurderMystery.git
Open the project in Unity (ensure you have Unity 2023.2 or higher installed).

Build and run the project through the Unity Editor.
